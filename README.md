# PCB-for-Stepper-Servo-Control
Hello everyone
this is PCB board for Stepper / Servo Control using stm32f411cue6 and 2 A4988 Stepper Motor Driver and servo motor driver 
to control 4 servo motors and 2 stepper motors 
i make connection between M1 M2 M3 of stepper motors with pin B0,1,10 so i can control the steps of the stepper motor from software side (full step 1/4 step , 1/8 , 1/16)
i used servo motor driver so in future we can add other servo motors without the need of changing the board and it only use i2c protocole to control the servo motor
